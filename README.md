# TempoHub NetEase Lyrics

让 EDIFIER TempoHub / Halo PixelBar 显示网易云歌词、系统音频频谱、消息通知和游戏性能曲线。

这是一个面向已经购买设备并安装了官方 TempoHub 的用户的非官方增强工具。
仓库不包含 EDIFIER 的原程序或资源文件；安装器只在用户本机读取官方安装，
生成一个独立的歌词补丁副本。安装过程不会修改官方安装目录。

## 当前开发状态

此提交用于手动验收，尚未作为稳定版发布。A160 设备已接入经典像素屏协议，
点击“应用显示”会上传当前画面并等待设备回执。通知场景按消息到达、到期和开关变化
更新设备画面；频谱、性能的自定义图像上传链路暂未开启连续推送，控制台预览独立更新。
设备本地频谱和动画的刷新应与上传过程区分。
此前记录的约 1.5 秒是一次图像上传、场景切换及回执等待的耗时，
不代表屏幕的每帧显示耗时，也不能据此推断硬件刷新率或频谱动画帧率。

GitHub 构建流程只打包，不自动运行测试；仓库保留手动检查脚本供自行验收。

## 功能

- 网易云桌面客户端播放时自动搜索、匹配并获取同步歌词。
- 优先读取网易云客户端当前歌曲的 `trackId`，直接获取歌词，避免搜索接口频繁触发限流。
- 使用歌曲标题、歌手、专辑和时长评分，降低 Live、Remix、伴奏、翻唱版本的误匹配。
- 直接读取网易云播放器的当前时间，拖动进度条后歌词立即重新定位。
- 启动补丁版 TempoHub 时，如果网易云音乐尚未运行，会自动拉起客户端并开启精确同步端口。
- 如果网易云已经运行但没有开启 `9222` 同步端口，插件会自动重启网易云一次以恢复歌词。
- 原生歌词模式下自动保持设备歌词屏开启。
- 支持 `-5 秒 ~ +5 秒` 歌词偏移，横向滑杆调整后自动应用。
- 网易云歌词不可用时回退到 TempoHub 原有的 QQ 音乐歌词逻辑。
- 左侧场景导航可在歌词、音频频谱、消息通知和游戏性能之间切换。
- 每个场景页都有“应用显示”按钮；设备确认传输和场景切换后，控制台才提示显示成功。
- 测试通知和启用 FPS 会自动切换到对应场景，不需要先手动切换页面。
- 音频频谱使用 Windows WASAPI 系统输出回环，支持 9 种样式：柱状频谱、纯净波形、双 VU 表、双翼镜像、峰值瀑布、能量脉冲、粒子星河、能量核心和霓虹山峦。
- 新频谱提供平滑回落、峰值拖尾、流动历史和音频驱动的粒子/轨道效果；在“音频频谱 → 频谱模式”中选择，设置自动保存。
- 消息通知支持微信、QQ 和 QQ 邮箱；优先使用 Windows 通知中心，并回退到未读窗口标题检测。
- 电脑性能支持四格曲线、环形仪表、全景趋势、科幻 HUD、电竞大字、极简数显六种屏幕布局；FPS、CPU、GPU、内存可分别开关。温度可用时在监控卡片和四格曲线中显示。
- 音效调优页可直接切换设备硬件 Music / Game / Movie 模式，并说明各模式的听感取向。
- 控制台启动、状态轮询、预览和设备操作使用异步请求，服务响应缓慢时仍可操作窗口。
- 连续调整会合并待发送设置；场景切换与测试通知保持顺序，旧场景的预览回包会被丢弃。
- 断线后自动降低重试频率，支持手动重新连接；最小化窗口时暂停预览请求。
- 支持小窗口滚动和自适应预览，播放进度平滑更新，操作结果在底栏单独显示。
- 控制台采用 macOS 风格的浅色侧栏、白色卡片、蓝色强调和矢量图标；通知拨钮支持动画与键盘操作，性能页使用独立指标卡片。
- 窗口使用一体化圆角外框和红黄绿控制按钮，支持标题区拖动、双击最大化、八方向缩放及 Alt+F4；关闭前保存逻辑保持有效。
- 设置使用缓存、串行合并和原子写入，避免并发保存覆盖以及重复读取磁盘。

### 本次问题修复

- 统一歌词偏移方向：正值提前、负值延后；已保存数值保持不变，旧版本用户可重新微调。
- 通知开关实际控制自动提醒，关闭后清除正在显示的对应提醒；手动测试通知仍可使用。
- 按窗口分别记录 QQ 未读标题，避免同一进程多个窗口造成重复提醒。
- 快速切换场景、进入音效页或重新开启歌词时，旧请求回包不再覆盖新的页面选择。
- 网易云同步超时或进度过期时显示异常状态，停止进度推算，并限制进度不超过歌曲时长。
- 音频设备启动、停止失败时仍关闭采集流，减少设备拔插后的资源占用。
- 关闭控制台时提交尚未保存的修改并等待写入；失败或超时会保留窗口，再次关闭可退出。
- 重新连接会刷新设置，同时保留当前浏览页面，避免旧读取结果覆盖新的或保存失败的修改。
- 静默更新通知拨钮时同步其显示状态；过长的错误提示会折行，完整内容可悬停查看。
- 设备尚未返回 EQ 能力时显示“待确认”，不再直接判定为不支持。
- 音效页使用现有设备连接，读取和切换操作统一由设备线程处理，不再依赖歌词模型初始化。
- 打开音效页时读取已缓存的能力信息，显式 EQ 查询的等待放在后台，不阻塞设备回执处理。
- 设备控制可在后续 USB 回执到来时补充初始化，处理插件模块先于 Qt 应用加载的启动顺序。
- 通知场景在消息到达、提醒结束或关闭对应提醒时提交新画面，避免屏幕停留在旧消息。
- 测试通知合并为一次保存设置和显示消息的操作，避免先上传空场景；通知变更也会使预览缓存失效。

## 安装

### 方式一：Release 安装器

1. 安装并登录官方 EDIFIER TempoHub，至少启动过一次设备。
2. 从本仓库的 Releases 下载 `TempoHub-NetEase-Installer.exe`。
3. 运行安装器。安装器会关闭正在运行的 TempoHub，并在
   `%LOCALAPPDATA%\TempoHubNetEase` 生成补丁副本。
4. 使用桌面的 **EDIFIER TempoHub - 网易云歌词** 启动。
5. 首次启动时，如果网易云已经在运行，启动器会询问是否重启一次网易云。
   重启只是为了开启本机 `127.0.0.1:9222` 的精确进度接口。

设置面板在桌面的 **EDIFIER TempoHub - 歌词显示设置**。如果 TempoHub
或网易云音乐尚未运行，设置快捷方式会自动启动它们。

### 方式二：从源码安装

需要 Windows、Python 3.10+，以及 `pip install pyinstaller`。

```powershell
git clone https://github.com/blankhcy-dot/TempoHub-2026.git
cd TempoHub-2026
python installer.py
```

安装器会自动下载 Python 3.9 运行库。它还需要官方 TempoHub 已经安装。

如果自动查找失败：

```powershell
python installer.py --app-dir "C:\Program Files (x86)\EDIFIER TempoHub"
```

## 使用说明

- 直接启动 **EDIFIER TempoHub - 网易云歌词**，网易云音乐未运行时会自动启动。
- 启动 **EDIFIER TempoHub - 歌词显示设置** 时，也会自动拉起 TempoHub 和网易云音乐。
- 如果设置面板提示“网易云精确同步端口 9222 未开启”，请关闭网易云，
  再从歌词快捷方式启动一次。
- 日志位于 `%TEMP%\tempo_hub_netease_lyrics.log`。
- 设置保存在 `%APPDATA%\TempoHubLyrics\settings.json`。
- FPS 由随安装包提供的 Intel PresentMon 采集，首次启用需要一次 Windows 管理员授权。
- CPU 温度取决于主板驱动权限；无法读取时会显示 `--`，其他性能指标不受影响。
- 控制台提供三个硬件 EQ 预设；自定义频段 EQ 的支持状态尚未确认，当前不提供频段滑杆。

## 卸载

运行 `%LOCALAPPDATA%\TempoHubNetEase\uninstall.ps1`。卸载器只移除补丁副本、
运行库和桌面快捷方式，不修改官方 TempoHub。

## 实现原理

TempoHub 使用 PyInstaller 和 Python 3.9 打包。安装器会：

1. 从用户自己的 `EDIFIER TempoHub.exe` 读取嵌入的 `PYZ.pyz`。
2. 保留所有原始模块，只替换 `app.utils.pixel_lyrics_util`。
3. 将原模块保留为 `app.utils.pixel_lyrics_util_orig` 供回退使用。
4. 生成新的 EXE，并通过 `_internal` 目录连接复用官方资源。
5. 通过网易云的本机调试端口读取播放器当前时间，通过本地 HTTP API 将
   设置和歌词状态提供给设置面板。

第三方组件和许可证说明见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 兼容性

当前版本按 2026-10-21 更新的官方 TempoHub Python 3.9 / PyInstaller 布局验证。
官方客户端更新后，模块路径或打包结构可能变化；如果安装器提示不兼容，
请提交 Issue 并附上 TempoHub 版本号和安装器错误输出。

## 开发与构建

修改 `src/app/utils` 后，使用 Python 3.9 重新生成 `payload`。构建脚本会自动执行
这一步，避免安装包仍然使用旧的字节码：

```powershell
./runtime39/python.exe scripts/compile_payload.py
./build_release.ps1 -Python python
```

以下检查脚本均需手动运行，不作为构建或推送的自动前置步骤。
有独立 PyQt6 环境时，可运行 `python tests/run_tests.py`。也可以复用本机官方
TempoHub 的 Python 3.9 Qt 运行库，无需启动设备或音乐客户端：

```powershell
./runtime39/python.exe tests/run_tests.py `
    --qt-app "C:\Program Files (x86)\EDIFIER TempoHub" `
    --snapshots build/qa --benchmark
```

数值回归检查另需 NumPy：`python tests/test_audio_spectrum.py`。测试覆盖慢请求
下的界面响应、请求顺序、超时与取消、场景预览隔离、断线恢复、小窗口布局、
并发设置保存、异常 HTTP 输入、FPS 并发采样和音频频谱数值一致性。
`--benchmark` 比较转换环节的新旧耗时，不代表整个应用的性能提升倍数。
